# CR-011-机器人图片生成功能

## 概述

为机器人添加AI图片生成功能，当机器人在发布动态时添加图片，有50%的概率使用AI生成图片而不是搜索图片。

## 功能需求

### 核心功能
1. **概率控制**：机器人在添加图片时有50%的概率使用AI生成
2. **提示词翻译**：使用Dify API将中文关键词翻译成适合AI图片生成的英文提示词
3. **图片生成**：调用Stable Diffusion API生成图片
4. **图片保存**：将生成的图片保存到本地文件系统
5. **动态关联**：将生成的图片作为附件添加到动态中

### 技术实现

#### 1. 集成现有Dify服务
- 使用现有的`DifyService`接口和`DifyServiceImpl`实现
- 调用`callDifyApi`方法进行提示词翻译
- 使用API Key: `app-hytQFbneWFbumZmDxXyOZfTQ`

#### 2. Stable Diffusion集成
- 创建`StableDiffusionClient`类处理SD API调用
- 支持图片生成和服务可用性检查
- 配置SD API端点和超时设置

#### 3. 图片处理流程
```
1. 生成搜索关键词 (PromptService)
2. 50%概率选择AI生成或图片搜索
3. 如果选择AI生成：
   - 构建翻译提示词
   - 调用Dify API翻译
   - 检查SD服务可用性
   - 调用SD API生成图片
   - 保存图片到本地
4. 如果AI生成失败或选择图片搜索：
   - 使用原有图片搜索逻辑
5. 将图片作为附件添加到动态
```

#### 4. 配置管理
- 在`application.yml`中添加Dify和SD API配置
- 支持超时设置和端点配置

## 风险评估

### 技术风险
1. **API依赖**：依赖外部Dify和SD API服务
2. **性能影响**：AI生成可能增加响应时间
3. **存储空间**：生成的图片需要本地存储空间

### 缓解措施
1. **服务检查**：在调用前检查服务可用性
2. **超时控制**：设置合理的API超时时间
3. **回退机制**：AI生成失败时自动回退到图片搜索
4. **存储管理**：定期清理生成的图片文件
