## 2. 变更描述

### 2.1 变更背景
当前系统中，用户与天使（robot）的互动仅通过UserRobotLink对象管理基础链接关系，缺乏对“熟悉度”成长、等级、主动行为等更丰富关系的支持。为提升用户粘性和互动体验，需要在原有对象和服务体系基础上，扩展熟悉度相关功能，并对robot的“内心困境”进行结构化管理。

### 2.2 变更目标
1. 在UserRobotLink对象中扩展熟悉度积分、等级等字段。
2. 支持通过评论、回复、聊天等行为提升熟悉度。
3. 熟悉度等级影响robot对用户的印象、主动行为及沟通内容。
4. robot的“内心困境”作为角色设定，归属RobotInfo，仅在chat逻辑中生效。
5. 增加沟通评分与积分奖励机制，为后续玩法扩展做准备。
6. 优化世界模块robot排序逻辑，提升交互效率。

### 2.3 变更内容
- 在UserRobotLink对象中新增熟悉度相关字段（familiarityScore、familiarityLevel、hasPendingMessage等）。
- 用户通过评论文章、回复评论、对话聊天等行为获得熟悉度积分。
- 定义熟悉等级升级机制, 等级为陌生人(0), 初识(1-10), 朋友(11-30), 好友(31-60), 密友(60+)
- 熟悉度升级时，robot会更新对用户的印象
- 达到好友熟悉度后，robot可主动发起对话，吐露“内心困境”, 如果是密友, 会更加频繁沟通
- robot的“内心困境”字段定义在RobotConfig的RobotInfo中，并同步到Robot对象，仅在robot主动创建对话时作为话题背景出现, 不参与帖子、评论, 普通对话等业务。
- 每次沟通结束后，系统对沟通, 按照心理学进行建设性行评分(0-10)，并将分数作为积分奖励给用户。
- 世界模块robot排序优先级：有待沟通消息 > 熟悉度高 > 已链接。

## 3. 影响分析

### 3.1 功能影响
- 影响模块：UserRobotLink管理、用户互动、世界模块、Robot配置与chat服务
- 影响功能：熟悉度成长、主动对话触发、沟通评分、robot排序
- 用户影响：用户可感知与robot关系成长，获得更多互动与奖励，体验更具个性的robot角色

### 3.2 技术影响
- 前端影响：UI需展示熟悉度等级、成长进度、robot主动消息提示
- 后端影响：需支持熟悉度积分计算、等级判定、印象更新、主动消息推送、沟通评分等逻辑
- 数据库影响：需为user_robot_link集合增加熟悉度积分、等级、hasPendingMessage等字段；robot的“内心困境”仅在RobotInfo配置中维护
- 用户增加积分属性, 默认0
- 第三方集成：暂无直接影响

## 5. 变更设计

### 5.1 后端相关设计

#### 1. user_robot_link集合结构扩展

| 字段名                | 类型         | 说明                   |
|----------------------|------------|----------------------|
| familiarityScore     | INT        | 熟悉度积分，初始为0     |
| familiarityLevel     | INT        | 熟悉度等级（枚举/数值） |
| hasPendingMessage    | BOOLEAN    | 是否有待沟通消息        |

> 说明：所有熟悉度相关字段均直接扩展在user_robot_link集合中，便于维护和查询。

#### 2. UserRobotLink.java实体类扩展

```java
    /**
     * 熟悉度积分，决定等级成长
     */
    private Integer familiarityScore = 0;

    /**
     * 熟悉度等级，枚举或数值型
     * 0-陌生人，1-普通，2-好友，3-密友等
     */
    private Integer familiarityLevel = 0;

    /**
     * 是否有待沟通消息
     */
    private Boolean hasPendingMessage = false;
```

#### 3. RobotConfig下的RobotInfo结构扩展

| 字段名         | 类型     | 说明                       |
|---------------|--------|--------------------------|
| hiddenTrouble | String | robot的内心隐瞒困境，仅用于chat |

- hiddenTrouble字段仅在RobotInfo（robot基础配置）中定义。
- 系统启动或robot加载时，同步到Robot对象实例，供chat服务读取。
- 不存储在user_robot_link集合中，避免冗余和职责混淆。

#### 4. 服务与接口设计

- UserRobotLinkRepository：增加相关逻辑, 负责熟悉度相关字段的增减、查询、更新。
- UserRobotLinkService：增加相关逻辑, 负责熟悉度积分计算、升级判定、印象管理、主动消息触发等业务逻辑。
- AIChatService：在用户熟悉度达到条件时，主动创建和用户的沟通
- UserRobotLinkController：增加熟悉度相关API接口。

### 5.2 前端相关设计

#### 1. 聊天模块

- 聊天界面需根据熟悉度等级判断是否主动根据内心困境来触发沟通。

#### 3. 其他组件

- 熟悉度进度条、等级徽章、robot主动消息提示组件。
